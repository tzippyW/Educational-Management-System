# Educational Management System 🎓

A React-based educational management system designed to support and manage a variety of academic activities and workflows.

The system provides dedicated functionality for managing students, courses, teachers, tasks, attendance, events, users, and communication.

## ✨ Main Features

- 👨‍🎓 Student management
- 📚 Course management
- 👩‍🏫 Teacher and lecturer management
- 📝 Tasks and questions management
- ✅ Attendance tracking
- 📅 Events management
- 💬 Chat functionality
- 👤 User management
- 📊 User activity tracking
- 📋 Todo and item management
- 🔐 Login and user profile management

## 🛠️ Technologies

### Frontend
- React
- JavaScript
- React Router
- Material UI
- Redux Toolkit

### Data & State Management
- Redux Toolkit
- Axios
- Local application state

### UI & Visualization
- Material UI
- Recharts
- React Big Calendar
- Swiper
- Emoji Picker
